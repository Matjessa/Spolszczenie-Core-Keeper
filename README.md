# Spolszczenie do Core Keeper

Stale wspierane polskie tłumaczenie do gry Core Keeper

W wypadku jakiegokolwiek błędu (technicznego/językowego), bądź pomysłu na inne tłumaczenie słowa/zdania zapraszam do kontaktu na Steam/Discord.

## Rzeczy jeszcze do zrobienia

- przetłumaczenie końcówki changelogu

- poprawienie nazw jedzenia


## Instalacja

> [!NOTE]
> Swoją aktualną wersję spolszczenia możesz zobaczyć w pliku README.txt dołączonym do spolszczenia, lub w ustawieniach gry

Aby pobrać spolszczenie wejdź w [link](https://github.com/Matjessa/Spolszczenie-Core-Keeper/releases/latest) a następnie na dole kliknij na plik Spolszczenie_Core_Keeper.v1_2.7z

Sposób instalacji:

    1. Wejdź w pliki gry (wybierz grę Core Keeper na Steam, kliknij w zębatkę po prawej stronie, potem wybierz "Zarządzaj" i następnie kliknj "Przeglądaj pliki lokalne").
    2. Wypakuj plik "Localization.csv do folderu po nazwą "localization".
    3. Jeśli masz poprzednią wersję spolszczenia wybierz opcję "Zamień plik w miejscu docelowym".
    4. Włącz grę, wejdź w ustawienia i zmień język na polski (pewnie będzie ostatni w kolejności).
    5. To tyle!
